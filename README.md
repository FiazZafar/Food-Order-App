# Food Order App — Android (Java)

A feature-rich Android food ordering application built with Java. Includes real-time maps, Firebase integration, product browsing, order management, and a complete user experience flow.

---

## Features

### Authentication
- User registration and login via Firebase Auth
- Secure session management

### Browsing
- Product listing with categories
- Category-based filtering
- Product detail screen

### User Features
- Favourites — save preferred items
- Order history — track past orders
- User profile with Cloudinary image storage

### Location
- Google Maps integration for delivery location

### Payment
- Stripe Api used for online payment

---

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Java |
| UI | XML, Material Design |
| Authentication | Firebase Auth |
| Database | Firebase Firestore |
| Image Storage | Cloudinary |
| Maps | Google Maps SDK |
| Backend | Spring Boot (not configured — backend required for full functionality) |
| IDE | Android Studio |

---

## Notes

> Backend (Spring Boot) is not included in this repository. Some features like live order processing may not function without a configured backend server. All Firebase and Maps features work independently.

---

## Getting Started

1. Clone the repository
```
git clone https://github.com/FiazZafar/Food-Order-App.git
```
2. Open in Android Studio
3. Add your `google-services.json` for Firebase
4. Add your Google Maps API key in `AndroidManifest.xml`
5. Add your Cloudinary credentials in the project constants
6. Run on emulator or physical device (Android 7.0+)
